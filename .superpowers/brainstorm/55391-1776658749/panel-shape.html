浮层 Panel 的形态方案

三个阶段（准备 / 录制 / 完成）的浮层怎么组织？

A

同一个 NSPanel，内容随状态切换

只有一个浮层窗口，始终存在。根据 overlayPhase 切换内部 View。准备态是宽面板，录制态收缩成小条，完成态展开成结果卡。

✓ 窗口层级简单
✓ 位置记忆连续
✗ 尺寸变化需要动画
✗ 三个阶段共用一个 NSPanel 逻辑复杂
🎛 准备态
宽面板 ~460×220
→
🔴 录制态
小条 ~320×56
→
✅ 完成态
结果卡 ~360×180
B

三个独立 NSPanel，按状态显示/隐藏

准备 Panel、录制 Panel、完成 Panel 各自是独立窗口，各自独立定位、独立动画。状态切换时 hide/show 对应窗口。

✓ 每个阶段逻辑完全隔离
✓ 尺寸形态自由
✗ 三个窗口要各自管理位置
✗ 录制态出现位置可能偏
🎛 PreparationPanel
独立窗口，准备时显示
🔴 RecordingPanel
独立窗口，录制时显示
✅ CompletionPanel
独立窗口，完成时显示
C

两个 NSPanel：主面板 + 录制小条

主面板承载准备态和完成态（两种宽度接近），录制态用一个独立的极简小条。录制开始时主面板隐藏、小条出现，录制结束时小条隐藏、主面板以完成态内容恢复。

✓ 主面板位置记忆连续
✓ 录制小条极轻量，不挡屏
✓ 分工最清晰
✗ 两个窗口之间要协调
🎛 主 Panel（MainOverlayPanel）
准备态 ↔ 完成态 内容切换
🔴 录制小条（RecordingHUDPanel） — 独立极简胶囊
录制中：主 Panel 隐藏，小条显示
录制结束：小条隐藏，主 Panel 重现（内容变为完成态）
